# Final Loop Challenge

A collection of twelve beginner-friendly Python mini-programs demonstrating
loops, functions, validation, collections, and menu-driven applications. The
complete solutions are available in `Final_loop_chall.ipynb`, and each task is
also exported as a runnable Python file.

## Programs

1. Student result management
2. Banking application
3. Inventory management
4. Quiz application
5. Number analysis
6. Employee salary analyzer
7. Shopping cart
8. Password strength checker
9. Prime number analyzer
10. Expense tracker
11. Mini authentication system
12. Super30 utility application

## How to run

The project uses only the Python standard library. Create and activate a
virtual environment if desired, then run any task from the repository root:

```text
python task_01/student_result.py
python task_10/expense_tracker.py
```

To work interactively, open `Final_loop_chall.ipynb` in VS Code, JupyterLab, or
Jupyter Notebook and run the cells for the task you want to explore.

## Concepts practiced

- `for` and `while` loops, nested loops, `break`, and `continue`
- Functions, return values, and reusable validation helpers
- Lists, dictionaries, strings, and formatted output
- Input validation and error handling with `try` / `except`
- Menu-driven programs and state managed across a loop

## Outcomes

Each program is self-contained and can be run independently. The notebook is
useful for guided practice, while the `task_01` through `task_12` folders make
the final solutions easy to execute, review, and reuse.
